### Rationale per directory

- **`sdk/`** — modules that import from `@anthropic-ai/claude-agent-sdk`
  or are tightly coupled to its types. The router lives here because
  it wraps the SDK pm; if a future alt-pm impl arrives, `lib/<alt>/`
  joins.
- **`telegram/`** — anything that crafts Telegram outbound payloads
  or parses Telegram inbound. Self-contained — could be lifted into
  a separate package.
- **`db/`** — SQLite + the per-table stores. Keeping migrations at
  the top level (`migrations/`) since they're operational artifacts.
- **`error/`** — classification + retry policy. Small directory but
  clean conceptual unit.
- **`agents/`** — per-chat agent loading. Small now; will grow when
  we add agent-loader subagent fan-out.
- **`approvals/`** — the canUseTool flow + UI builders + waiter
  factory. The cleanup found `approval-waiters.js` orphan; in this
  layout the wire-up gap is more visible.
- **`ipc/`** — Unix socket server + client + file param validator.
- **Root `lib/`** — cross-cutting primitives that EVERY layer above
  uses. Don't sub-categorize for the sake of it.

## Phase C — Coverage push to 95%

After Phase B, run coverage and identify per-file gaps. Strategy:

1. Run coverage; sort by line% ascending.
2. For each file < 95%, identify uncovered branches (the line ranges
   in the coverage output).
3. Add targeted unit tests for those branches.
4. Avoid contrived tests — if a branch is dead code OR pure defensive
   error handling for impossible states, document and consider
   deleting.

Files known to be below 95% today:
- `lib/process-manager-sdk.js`: 80.54% — gaps in error paths, eviction, compact-boundary handling.
- `lib/voice.js`: 71.23% — happy-path coverage missing.
- `lib/process-guard.js`: 88.75% — orphan-cleanup edge cases.
- `lib/ipc-server.js`: 86.58% — auth path covered in C12 but other branches still gapped.
- `tests/helpers/db-fixture.js`: 74.36% — test-only utility, low priority.
- `scripts/split-db.js`: 64.71% — operational script, low priority.

Target: every `lib/**/*.js` file >= 95% line coverage. Tests can stay
< 95% (they're already proving they work by passing).
